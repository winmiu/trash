# 公平骰 v1.9.0

开启「扩展 → 公平骰 → 当前聊天启用」后，公平骰把本机骰点和判定表一次性放进这一轮正文输入，酒馆用原有主预设生成回复。旧版升级后自动使用同一条路径，沿用当前聊天的开关和事件权重。

## 骰子判什么

- 行动和交锋只判本次尝试成功或失败。主预设结合角色卡和剧情决定之后发生什么，以及怎样写进正文。
- 角色卡里的战力可以留空。正文模型在同一次生成里根据双方已有表现、当前状态、人数和世界规则选用判定表。证据不足时可以暂缓。闲聊或已确定的事情直接叙述。
- 自然转场和 NPC 未决选择可参考各自的权重。当前剧情较适合的条目可乘 2，较不适合的乘 0.5，其余保持原权重。面板内可展开「事件与反应权重」修改这个聊天的基础值。
- 同一回合重新生成时复用本机候选。普通生成、重新生成、切换到需要生成的新候选和续写都通过酒馆原有的正文请求处理。

## 查看运行情况

展开「运行日志」。新版记录写有「一次性注入」，会显示是否成功写入正文输入，以及准备的候选 d100。具体采用的分支留在主模型这次生成中，插件没有单独的模型调用，也不要求在回复末尾附上判定记录。升级前的运行记录按原时间保留。

## 安装

在酒馆「扩展 → 安装扩展」粘贴 `https://github.com/winmiu/trash.git`。已安装时使用扩展管理中的更新按钮，然后刷新页面，在公平骰面板底部确认版本为 v1.9.0。

手动安装可将 ZIP 解压到酒馆的 `data/<用户名>/extensions/fair-dice/`，确保该目录直接包含 `manifest.json`。若原来已安装，请使用原扩展目录，以免重复加载。
