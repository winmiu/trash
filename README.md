# Fair Dice · 公平骰子（SillyTavern 扩展） v1.4.0

独立于角色卡、世界书和正则的 **跑团裁定 + 真实掷骰 + 加权事件** 前端扩展。作者署名：winmiu。

在「扩展 → 公平骰子」的「当前聊天启用」下方，展开 **运行日志** 即可查看。日志默认收起，按聊天保存最近 20 次运行，最多保留最近使用的 40 段聊天。日志从 v1.4.0 加载后开始记录。

每次运行按时间列出酒馆的生成信号、是否进入判定、裁判依据、实际骰点或加权抽签结果，以及是否把指引交给酒馆。重新生成会注明是否复用了骰点。模型连接失败、回复格式错误、战力资料不足和正常无须掷骰会分别显示。查看日志不会发起模型请求。

## 最重要的区别：先裁定，再掷骰，最后叙事

勾选「独立AI裁判」时，插件对每个新的用户回合使用 **当前SillyTavern配置的模型额外调用一次** `generateQuietPrompt`：

1. **独立裁定**（简短JSON）：是否有必要掷骰？当前是普通叙事、行动检定还是战斗交锋？是否出现自然转场或NPC尚未决定的选择？角色能力、人数、装备、难度和风险有哪些客观依据？
2. **程序掷骰**：当需要检定时，插件通过浏览器随机数（优先 `crypto.getRandomValues`）执行权重抽签或d100。AI不自行决定骰点，也不在掷骰前决定输赢。
3. **注入结果**：生成主回复前，用官方扩展接口 `setExtensionPrompt` 告诉AI裁定结果，要求遵守、不代替玩家行动、不展示骰子算法。不会修改角色卡/MVU/原有聊天消息。

独立裁定只保存**可检查的简短理由与数值依据**，不是请求或展示模型的私密思维链。最终叙事模型仍可能偏离注入规则；本版本不会自动检查并重生成不服从骰子的回复。

## 安装

**A. GitHub仓库安装（最适合分享）**

打开 SillyTavern 的「扩展 → 安装扩展」，粘贴 `https://github.com/winmiu/trash.git`，选择当前用户或所有用户。安装后刷新页面，打开「扩展 → 公平骰子」。运行酒馆的设备需要安装 Git。

**B. 无GitHub的本地安装**

解压ZIP后，将根目录改名为 `fair-dice` 并放入：
- `SillyTavern/data/<用户名>/extensions/fair-dice/`（当前用户）
- 或 `SillyTavern/public/scripts/extensions/third-party/fair-dice/`（所有用户）

请确认 `fair-dice/manifest.json` 直接存在；刷新或重新启动酒馆，然后在「扩展」中找到“公平骰子”。**不要放到正则列表、角色脚本或世界书里**。

## 用法

默认**当前聊天不开启、前置AI裁判预选开启**，由用户主动开启，避免意外额外API费用。

进入聊天后在「扩展 → 公平骰子」中：
1. 开启「当前聊天启用」；
2. 可选开启「独立AI裁判」：每个新回合多调用当前模型一次，返回简短的JSON裁定；
3. 保持「自动识别」或切换到固定「事件方向／事件检定／战斗检定」；
4. 选择「公平中立」「生活日常」「变化较多」之一，或逐项修改事件与NPC反馈权重；
5. 可点击「AI评估当前场景」预先进行一次独立裁定；点击「抽签并锁定下一回复」可人为锁定一次结果。

关闭当前聊天开关后，插件清除自己的提示词注入；其他聊天不受影响。

### 判定行为

- **本轮无需骰子**：闲聊、明确的常规行为、已确定的事实，原则上都不摇骰，也不强行加戏。
- **事件方向**：只在合适的自然转场抽事件权重；NPC反馈只有在存在真实未决选择时才独立抽取。默认65%“延续当前情境”。
- **行动检定**：依据难度以及已知的准备/环境修正计算d100成功率。客观不可能的行动成功率为0%。
- **战斗检定**：按0—100有效战力、人数、装备地形与伤势，一骰只判**一次交锋**。采用“自动适配世界观”时，现代现实背景不强行套武侠阶位；武侠背景可采用严格五阶差。不允许一个人无理由正面击败成建制大量敌人。
- **没有战斗等级**：AI在有文本证据且具有中高置信度时可临时估计有效战力；如证据不足则返回 `null`，默认不掷硬胜负骰（可以手动填写）。估算不写入角色卡。
- **公平原则**：NPC可以有正当理由帮助或拒绝玩家；不会仅因为是`{{user}}`就获胜，也不刻意制造失败。
- **重生成**：同一用户回合尽量沿用判定与骰点；修改消息或进入下回合才重新判定。

### 预设与面板

可自定义事件名称、文字说明、是否启用、权重（＋/－），插件会按权重总数归一化为百分比。设置储存在酒馆扩展配置中，不修改角色卡。

### 费用、隐私与兼容

- **独立AI裁判开启时**：每个新的判定回合额外请求一次当前模型，增加延迟及Token费用；关闭则不额外调用。
- 额外裁判请求遵循你已经选择的SillyTavern模型/API供应商的数据规则。本扩展本身不请求第三方服务。
- 若模型返回无效JSON，自动判定**本轮跳过随机**，不杜撰结果；可以关掉独立裁判或手动设置模式再试。
- 不保证与所有高强度预设/重写插件兼容。建议停用同时对同一段叙事做判定的其他扩展，防止重复骰子和互相矛盾。
- 不支持读取任何模型内部私有思维链；只使用有限的JSON结果和可见依据摘要。

## v1.3 更贴近多角色卡跑团的改动

- **每个聊天独立保存事件权重和NPC反馈权重**：武侠卡与现代都市卡互不污染。默认按公平中立模板初始化。
- **前置AI裁判预选开启，聊天开关仍默认关闭**：一旦启用当前聊天，先判断有没有必要摇骰；普通聊天和无风险行动可以不摇。额外消耗一次模型调用；如不需要可取消。
- **没有等级时审慎估计**：裁判须说明行动方与对手的能力来源、具体事实及置信度。无法举证时返回未知并暂缓胜负骰。
- **防错初始化**：扩展在APP_READY已触发后开启仍能初始化UI。
