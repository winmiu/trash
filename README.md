# 公平骰 v1.9.1

开启「扩展 → 公平骰 → 当前聊天启用」后照常发消息即可。公平骰把判定规则、骰点和候选表一次放进正文输入。正文模型结合它本轮能看到的角色卡、世界设定和聊天内容，选择适用的判定，并按主预设写故事。

## 每轮怎样判定

- **先判有没有悬念。** 闲聊、尚未实行的打算或已经确定的事直接承接。行动和交锋只判当下目标的成败，具体后果由主预设写。
- **行动看任务和人。** 同一把待修的锁，任务门槛相同。熟悉这种锁、工具齐全，或手受伤、工具短缺，都会影响当下的判定。
- **交锋看这一合争什么。** 抢先拦住对方与正面压制对方，可以有不同的强弱关系。没写战力数值也能用双方的训练和过往表现判定，再考虑伤势、位置及实际人数。确实缺少关键依据时暂缓定胜负。
- **事件看局势，NPC 看动机。** 转场时根据时间、地点和未完事务评估事件。人物确有选择时，按关系、承诺和代价评估反应。各项每轮重新采用两倍、原值或一半权重，和设定冲突的条目跳过。面板中的基础权重仍可按聊天调整。
- 同一回合重新生成时复用本机候选。普通生成、重新生成、切换到需要生成的新候选和续写都通过酒馆原有的正文请求处理。

## 查看运行情况

展开「运行日志」可查看本次是否成功注入、送入哪些分支规则，以及备好的候选骰点。骰点出现在日志中只表示它可供本轮使用。正文模型只生成正常回复，插件不会收到模型最终采用的分支或系数。

## 安装

在酒馆「扩展 → 安装扩展」粘贴 `https://github.com/winmiu/trash.git`。已安装时使用扩展管理中的更新按钮，然后刷新页面，在公平骰面板底部确认版本为 v1.9.1。

手动安装可将 ZIP 解压到酒馆的 `data/<用户名>/extensions/fair-dice/`，确保该目录直接包含 `manifest.json`。若原来已安装，请使用原扩展目录，以免重复加载。
